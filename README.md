# Página personal - Fernando Fonseca

Proyecto de la guía **Frontend Básico** de Diseño de Sistemas en Internet.

Esta página es una presentación personal. Incluí información sobre mis estudios, intereses, algunos trabajos de clase y enlaces a mi perfil de GitHub.

## Contenido de la carpeta

- `index.html`: textos, encabezados, listas, imágenes y enlaces.
- `css/styles.css`: diseño y ajustes para celulares.
- `img/`: ilustraciones utilizadas dentro de la página.

## Para verla

Abrí `index.html` en el navegador. También se puede abrir desde Visual Studio Code con **Live Server**. No hay que instalar programas adicionales para la página.
